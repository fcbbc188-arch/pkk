# 经典FC红白机坦克大战 (Battle City 1990) - 电脑手机跨端网页版

复刻 1990 经典红白机（NES/FC）《坦克大战》游戏，采用纯原生标准 Web 技术栈（HTML5 Canvas + 原生 JavaScript + CSS3）开发，无任何第三方依赖与构建步骤，开箱即玩！

---

## 🌟 核心特色

1. **跨端全自适应**：
   - **电脑端**：支持 `W A S D` 或 `方向键` 移动，`Space` 或 `J` 键开火，`P` 键暂停，`M` 键静音。
   - **手机触控端**：竖屏游戏画面居中，下方配备街机十字方向键（支持滑动操作）与加大触控开火按键。
2. **纯代码 8-Bit 实时音效合成器**：
   - 基于 **Web Audio API** 实时合成开火、爆炸、吃道具、老鹰损毁、关卡开场曲等经典 8-bit 音效。
   - 零外部 MP3/WAV 音频文件加载依赖，秒开无延迟，支持一键静音。
3. **经典地形与微网格物理**：
   - 🧱 **红砖**：可被子弹逐块击毁。
   - 🛡️ **铁墙**：普通子弹被弹开，四阶重坦或暴击炮可击碎。
   - 🌊 **水面**：坦克无法通过，子弹可穿透飞行。
   - 🌿 **草丛**：遮挡坦克视线，支持草中隐蔽伏击。
   - 🧊 **冰面**：提供惯性滑行效果。
   - 🦅 **老鹰基地**：守护核心，被毁即判负。
4. **4 级敌军编制与智能战术 AI**：
   - 🚜 **普通装甲车**：平衡型巡逻。
   - ⚡ **急速轻坦**：高移速突袭，善于绕后偷家。
   - 💥 **强击炮坦**：超高速穿透弹，破坏力强。
   - 🛡️ **重装巨坦**：拥有 4 点生命值，受击逐级变色（绿→黄→红）。
   - ✨ **红光闪烁宝物车**：击杀必爆随机掉落强化道具！
5. **豪华 8 大强化道具系统**：
   - ⭐ **五角星**：火炮进阶（单发速射 -> 双管连发 -> 毁铁重炮）。
   - 🛡️ **钢盔**：获得 12 秒无敌防护罩。
   - 💣 **手雷**：全屏连环大爆炸轰杀在场所有敌军。
   - ⏱️ **怀表**：全场敌军定身冻结 10 秒。
   - ⛏️ **铁铲**：老鹰基地周边瞬间替换为精钢防线（到期前闪烁警告）。
   - 🎖️ **加命坦克**：生命值额外 +1。
   - 🚀 **火箭靴（扩展）**：履带超频高速冲刺。
   - ⚡ **激光炮（扩展）**：高穿透暴击重炮。
6. **关卡战役与地图编辑器**：
   - 内置 5 大经典主题战役关卡，支持关卡自由选择。
   - 内置 **自定义地图编辑器**：支持点击与触控拖拽涂抹，自由设计关卡并一键保存与试玩，支持 JSON 导出与导入分享。

## 🚀 启动游玩方式

### 方式 1：本地直接双击打开
在电脑上直接双击打开项目根目录下的 `index.html` 即可畅玩。

### 方式 2：使用本地轻量 HTTP 服务（支持局域网手机扫码游玩）
在终端中执行：
```bash
python3 -m http.server 8080
```
- 电脑端访问：`http://localhost:8080`
- 手机端访问：确保手机与电脑在同一 Wi-Fi，访问 `http://<你的电脑内网IP>:8080`
